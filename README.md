# FR Legends Corner Workshop

Independent static resource for FR Legends driving, cars, cornering, drifting, tuning, practice and troubleshooting.

## Render service name

`fr-legends-corner-workshop`

## Planned URL

https://onrender-pyfl.onrender.com/index.html

## Deployment

Create a Render Static Site using the exact service name above and publish the project root. No build command is required.

Every page has a self-referencing canonical. The sitemap and robots.txt use the same planned domain.

If Render assigns a different final URL, update every canonical, sitemap.xml and robots.txt to that exact URL before indexing.

This is an independent community resource and is not affiliated with or endorsed by the game developer.
