Troubleshooting

Find where the problem starts before trying random fixes.

A structured approach to installation, startup, loading, update and gameplay problems.

Identify the failure stage

First decide whether the issue appears during installation, startup, loading, gameplay or immediately after an update. The exact stage narrows the problem much more than saying that the game simply does not work.

Installation

Check available storage, basic compatibility and possible conflicts with an older installation. Avoid repeatedly changing versions without recording the result of each attempt.

Startup

Restart the device and close unnecessary background applications. If the problem began after an update or configuration change, record that detail before making more changes.

Loading and freezing

Test after a clean restart and note whether the freeze happens everywhere or only after a particular action. A location-specific symptom gives you a narrower diagnostic target.

After an update

Record the exact version and compare behavior before and after the change. Version and device information make troubleshooting much more precise.

Diagnosis record: device → version → exact symptom → when it happens → last relevant change → result of each test.

Use this order

  1. Restart the game and device.
  2. Check storage and basic compatibility.
  3. Identify the failure stage.
  4. Review the latest relevant change.
  5. Test one fix at a time.
  6. Record the result.
